# Retired page routes

These `.astro.txt` files preserve the former routes when the public site was
reduced to Home and CV. They are not in Astro's pages directory and are never
published. Markdown content and original gallery assets remain in place.

To deliberately restore a page, copy its snapshot back to the corresponding
`src/pages/` location, remove `.txt`, restore the required styles/navigation, and
update route validation. Publications and selected work already appear in CV.
